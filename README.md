# Meow Cup Landing

A premium product landing page concept for a ceramic cat mug and saucer.

## Overview

This project uses a small image set to build a more editorial product website around:

- product silhouette
- ceramic glaze detail
- brand mark emphasis
- multi-angle storytelling
- interactive hover and pointer lighting

## Tech Stack

- React 18
- Vite 5
- GSAP + ScrollTrigger
- Plain CSS

## Structure

```text
src/
  App.jsx
  content.js
  main.jsx
  styles.css
  components/
    PhotoCard.jsx
  hooks/
    useLandingAnimations.js
    usePointerGlow.js
images/
  *.png
```

## Commands

```bash
npm install
npm run dev
npm run build
```

## Notes

- The site is intentionally 2D and image-led.
- Original PNG assets are still in use and can be optimized later.
