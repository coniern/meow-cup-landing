Ceramic Cat Mug — Vite + R3F Landing

Place a GLB/GLTF model named `cat_mug.glb` into `public/models/` (model should contain separate nodes named `Mug` and `Saucer` for the separation animation).

Commands:
  npm install
  npm run dev

Notes:
- Model file is not included. Use a high-quality GLB exported with separate nodes for Mug and Saucer.
- Tune DPR in Scene.jsx for performance on mobile.
